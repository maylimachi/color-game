# 🎨 Color Game

Un juego interactivo para practicar la identificación de colores RGB.  
El objetivo es adivinar el color correcto a partir de un código RGB mostrado en pantalla.

---

## 🕹️ Cómo jugar

1. Al iniciar el juego, se muestran varios cuadrados de colores.
2. En la parte superior aparece un código RGB (por ejemplo: `rgb(120, 45, 200)`).
3. Debes hacer clic en el color que creas que corresponde a ese código.
4. Si aciertas 🎉, todos los cuadrados cambian al color correcto y podrás volver a jugar.
5. Si fallas ❌, el cuadrado desaparecerá y podrás seguir intentando.
6. Podés elegir entre **modo fácil (3 colores)** o **modo difícil (6 colores)**.

---

## 🧠 Tecnologías utilizadas

- **HTML5** – estructura del juego  
- **CSS3** – estilos y animaciones  
- **JavaScript (DOM)** – lógica e interactividad  

---

## 🚀 Funcionalidades

- Generación aleatoria de colores RGB.  
- Detección de aciertos y errores.  
- Cambio dinámico del fondo y mensajes.  
- Dificultad ajustable (fácil / difícil).  
- Efecto de sonido al acertar.
